The Apache License 2.0 includes its own warranty disclaimer and limitation-of-liability provisions. Livariant does not add a separate product warranty through the Public Preview documentation.

Public Preview support documentation describes engineering expectations for supported paths; it does not create a paid support SLA, guarantee uninterrupted operation, or override the `LICENSE` terms.

## Contributions

Contribution rules are documented in `CONTRIBUTING.md`. Intentionally submitted contributions are expected to be provided under the repository's Apache-2.0 terms unless explicitly stated otherwise before submission.

## Third-party material

The current dependency/redistribution review is summarized in `THIRD_PARTY_NOTICES.md`. The packed Livariant Runtime currently declares no runtime dependencies. Build-only development dependencies remain subject to their upstream licenses.

**Livariant** is the accepted product name. The repository's preliminary naming/collision review is documented in `distribution/product-naming-decision.md`.

That engineering review is not a formal trademark-clearance opinion. The architecture remains rename-safe if a future credible rights conflict requires a branding change.
